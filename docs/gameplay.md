# 《噬主：魔王胚胎》玩法说明

## 1. 核心定位

《噬主：魔王胚胎》是一款反英雄题材的轻 2.5D 割草游戏。

玩家不是勇者，而是藏在地牢深处的邪恶核心。勇者讨伐军不断从四周涌入，试图在魔王孵化前摧毁核心。玩家需要操控核心移动，依靠身边的小怪军团抵御勇者，收集勇者死亡后留下的腐血筹码，并用腐血驱动血肉老虎机，让弱小怪物逐步成长，最终融合成真正的魔王。

游戏的核心体验是：

```text
弱小核心苟活
小怪护主作战
勇者持续进攻
杀敌掉落腐血
腐血驱动老虎机
老虎机强化小怪与胚胎
胚胎孵化魔王
魔王带领怪群反杀勇者军团
```

一句话记忆点：

```text
这是一个用勇者当筹码，靠老虎机孵化魔王的像素割草游戏。
```

## 2. 玩家扮演对象

玩家控制的是一个正在孵化魔王的邪恶核心。

邪恶核心本身不应像传统主角一样强大。游戏前期，核心更像一个脆弱胚胎，需要依靠周围的小怪保护自己。玩家的主要职责不是直接砍杀敌人，而是：

```text
移动核心，躲避勇者包围
引导小怪接敌
靠近尸体区收集腐血
选择老虎机奖励
推动魔王胚胎成长
在觉醒后进入反杀阶段
```

核心拥有生命值、腐血经验、胚胎值和当前小怪数量等关键状态。

## 3. 基础操作

基础操作应保持简单，便于黑客松 Demo 快速上手。

推荐操作：

```text
WASD / 方向键：移动邪恶核心
Q：血肉震荡，释放圆形范围冲击
鼠标 / 按钮：选择老虎机奖励
Esc：暂停
```

首版可以不强依赖复杂主动技能。游戏的主要战斗输出来自小怪自动攻击和魔王觉醒后的强化能力。

## 4. 核心循环

一局游戏的基础循环如下：

```text
1. 玩家进入地牢，控制邪恶核心移动
2. 初始小怪围绕核心巡游
3. 勇者从屏幕外不断进入
4. 小怪自动寻找附近勇者并攻击
5. 勇者死亡后掉落腐血
6. 玩家靠近腐血，腐血被磁吸并吸收
7. 腐血填充经验条和胚胎值
8. 经验满后触发血肉老虎机
9. 玩家从老虎机奖励中选择成长方向
10. 玩家也可以花费腐血筹码，将指定小怪升格为精英怪
11. 精英小怪帮助玩家撑过中期压力
12. 战斗继续，敌人波次增强
13. 胚胎值满后触发魔王最终开奖
14. 小怪融合，魔王觉醒
15. 魔王带领怪群进入反杀高潮
16. 圣骑士 Boss 登场
17. 击败 Boss 后进入屠杀报告结算页
```

核心节奏应该从“被围攻的求生”逐渐转向“觉醒后的碾压”。

## 5. 战斗体验

战斗的目标不是复杂操作，而是让玩家感受到小怪军团逐渐成形、勇者讨伐军逐渐失控、魔王胚胎逐渐不可阻止。

前期体验：

```text
玩家脆弱
小怪数量有限
勇者压力明显
需要主动走位拾取腐血
老虎机奖励带来第一次喘息
```

中期体验：

```text
小怪数量增加
攻击频率变高
腐血掉落更密集
老虎机奖励开始形成流派
玩家开始花费筹码定向培养精英小怪
胚胎值接近满格
勇者喊话从自信变成恐惧
```

后期体验：

```text
魔王觉醒
小怪被吸入核心并融合
玩家获得明显强化
大范围攻击和高密度击杀出现
勇者军团被反向屠杀
圣骑士 Boss 作为最终抵抗登场
```

## 6. 小怪系统

小怪是玩家前期的主要战斗力，也是魔王觉醒的养料。

小怪围绕邪恶核心移动，并在敌人靠近时自动脱离轨道攻击。攻击结束后，小怪会回到核心附近，继续保护核心。

首版推荐小怪：

| 小怪 | 定位 | 玩法作用 |
|---|---|---|
| 骷髅 | 近战输出 | 伤害高，攻速较慢，适合清理贴脸敌人 |
| 蝙蝠 | 快速骚扰 | 移动快，攻速高，适合追击残血敌人 |
| 史莱姆 | 范围/毒爆 | 可在后续版本加入死亡毒爆或减速效果 |
| 哥布林 | 功能/拾取 | 可在后续版本提升拾取范围或投掷炸弹 |

黑客松首版可以优先做骷髅和蝙蝠，确保两者有清晰差异。

精英小怪是中期过渡的关键成长目标。

玩家可以花费腐血筹码，通过老虎机将指定小怪升格为精英怪。精英怪不是最终魔王，而是魔王觉醒前的强力护卫，用来填补“普通升级已经不够爽，但魔王还没孵化”的中期阶段。

精英小怪设计目标：

```text
给玩家一个可控成长目标
让玩家能定向投资自己喜欢的小怪
缓解中期敌人强度上升带来的压力
让最终魔王觉醒前有明显战力台阶
为最终融合魔王提供叙事铺垫
```

精英升格示例：

| 普通小怪 | 精英形态 | 强化方向 |
|---|---|---|
| 骷髅 | 骸骨队长 | 近战范围扩大，攻击附带劈砍 |
| 蝙蝠 | 血翼尖啸者 | 攻速提高，攻击可短距离弹射 |
| 史莱姆 | 腐浆母体 | 周期性留下毒液区域 |
| 哥布林 | 赌命工匠 | 投掷炸弹，并提升腐血拾取收益 |

首版可以只做 2 个精英形态：

```text
骸骨队长
血翼尖啸者
```

这样能在较低开发成本下，让玩家感受到“我正在把一群杂兵养成魔王军干部”。

## 7. 勇者敌人

敌人不是传统意义上的怪物，而是讨伐魔王胚胎的勇者军团。

首版推荐敌人：

| 敌人 | 定位 | 行为 |
|---|---|---|
| 义勇兵 | 基础近战 | 从四周涌入，追击邪恶核心 |
| 弓箭手 | 远程骚扰 | 保持距离，向核心射击 |
| 突击骑士 | 精英冲锋 | 偶尔快速突进，制造走位压力 |
| 圣骑士 Boss | 最终抵抗 | 魔王觉醒后登场，拥有冲锋、召唤和范围圣光 |

v0.1 可以先做义勇兵、弓箭手和圣骑士 Boss。突击骑士可作为后续扩展。

## 8. 腐血系统

腐血是勇者死亡后的核心掉落物，也是游戏成长和主题表达的关键资源。

腐血同时承担三种含义：

```text
经验值
老虎机筹码
魔王胚胎养分
```

基本规则：

```text
勇者死亡后掉落腐血
腐血会在地面短暂停留
数秒后腐烂消失
玩家靠近后腐血被磁吸
吸收腐血后提升经验和胚胎值
经验满后触发老虎机
积累的腐血筹码可用于定向升格精英小怪
胚胎值满后触发魔王最终开奖
```

腐血会过期这一点很重要。它会迫使玩家离开安全位置，主动冲向尸体堆，从而制造风险和收益之间的拉扯。

## 9. 血肉老虎机

血肉老虎机是游戏的核心卖点之一。

它不是普通升级面板，而是将“杀勇者获得腐血筹码”转化成视觉和叙事记忆点的系统。

触发条件：

```text
腐血经验条填满
```

流程：

```text
战斗暂停或进入慢动作
老虎机面板弹出
三个滚轮开始转动
滚轮逐个停下
生成三个候选奖励
玩家选择其中一个
奖励立即应用到战斗
战斗继续
```

奖励示例：

```text
小怪数量 +1
骷髅伤害 +25%
蝙蝠攻速 +25%
腐血拾取范围 +30%
血肉震荡冷却降低
腐血掉落量增加
胚胎值额外增长
下一次老虎机出现稀有奖励概率提升
```

老虎机的反馈必须明显：

```text
滚轮音效
逐格停顿
奖励稀有度颜色
选择后的血肉脉冲
战斗恢复时的短促冲击
```

### 9.1 精英升格老虎机

精英升格老虎机是中期过渡玩法。

普通升级老虎机偏随机，负责提供局内成长变化；精英升格老虎机偏定向，允许玩家消耗腐血筹码，把指定小怪培养成精英怪。

触发方式：

```text
玩家积累足够腐血筹码
打开精英升格入口
选择一个当前存活的小怪或小怪类型
投入筹码启动老虎机
老虎机决定升格结果或附加词条
目标小怪变成精英怪
```

推荐规则：

```text
每次精英升格消耗固定数量腐血筹码
只能选择当前已拥有的小怪类型
每种小怪首个精英升格成本较低
重复升格同类精英成本递增
精英小怪死亡后不立刻永久消失，可在一段时间后从核心中重生
魔王觉醒时，精英小怪提供更高融合权重
```

升格结果可以分成两层：

```text
基础升格：普通小怪变为对应精英形态
附加词条：老虎机额外滚出一个强化方向
```

附加词条示例：

```text
嗜血：击杀后短时间攻速提高
骨裂：攻击附带小范围溅射
腐烂：命中敌人后留下持续伤害
护主：核心受伤时立刻回防
赌徒：每次攻击有概率额外掉落腐血
```

这个系统解决两个问题：

```text
玩家在魔王觉醒前有更明确的中期追求
玩家不完全依赖随机升级，可以对小怪军团做定向培养
```

黑客松首版实现可以简化为：

```text
腐血筹码达到阈值后出现“升格小怪”按钮
玩家选择骷髅或蝙蝠
播放一个短老虎机动画
直接生成骸骨队长或血翼尖啸者
附加词条先不做，或只做 2 个随机词条
```

## 10. 魔王胚胎与最终开奖

胚胎值代表魔王的孵化进度。

随着玩家不断吸收腐血，胚胎值逐渐上涨。当胚胎值满后，游戏进入魔王觉醒流程。

觉醒流程：

```text
全场慢动作
勇者行动停滞
小怪被吸入邪恶核心
血肉老虎机变成最终开奖
三栏符号滚动
符号定格
魔王形态生成
核心破裂，魔王诞生
战斗进入反杀阶段
```

最终老虎机三栏：

```text
[ 主种族 ] [ 器官 ] [ 权能 ]
```

示例结果：

| 主种族 | 器官 | 权能 | 魔王形态 |
|---|---|---|---|
| 骷髅 | 王冠 | 火焰 | 骸焰魔王 |
| 蝙蝠 | 巨翼 | 吸血 | 血翼魔王 |
| 史莱姆 | 巨口 | 毒液 | 腐蚀魔王 |
| 哥布林 | 机械臂 | 雷电 | 雷暴暴君 |

黑客松首版不需要实现完整组合系统。可以先做 3 个预制魔王形态，保证开奖演出和战斗强化足够明显。

## 11. 魔王觉醒后的反杀阶段

魔王觉醒是整局游戏的情绪转折点。

觉醒前：

```text
玩家被勇者压迫
小怪保护核心
玩家围绕腐血冒险移动
```

觉醒后：

```text
玩家获得更强攻击
小怪军团变得更凶猛
腐血掉落和击杀密度上升
勇者喊话从进攻变成恐惧
圣骑士 Boss 被迫登场
```

魔王阶段应该明显比前半段爽，而不是只换皮。至少需要有：

```text
更大攻击范围
更高击杀频率
更强屏幕反馈
新的大招或自动爆发
Boss 战压轴目标
```

## 12. Boss 与胜利条件

圣骑士 Boss 是勇者军团的最后抵抗。

推荐触发方式：

```text
魔王觉醒后一段时间，圣骑士 Boss 登场
```

Boss 行为：

```text
追击魔王
发动圣光冲锋
召唤义勇兵
释放圆形净化爆环
血量降低后进入第二阶段
```

胜利条件：

```text
击败圣骑士 Boss
```

失败条件：

```text
邪恶核心或魔王生命值归零
```

Boss 不需要复杂 AI，但必须提供清晰压轴感。

## 13. 结算页

击败 Boss 或玩家死亡后进入结算页。

结算页名称建议：

```text
屠杀报告
```

显示内容：

```text
击杀勇者数
吞噬腐血量
孵化魔王形态
最大连杀
献祭小怪数量
圣骑士是否被击败
七圣王国损失评估
最终评级
```

评级示例：

```text
灾厄
噩梦
坠渊化身
终末魔王
```

结算页必须提供重新开始入口。

## 14. 叙事与文本反馈

游戏叙事不依赖长剧情，而依赖短句播报、勇者喊话和系统提示。

勇者喊话示例：

```text
为了七圣联合王国！
别让那个东西孵化！
净化地牢！
它在吃我们的血！
圣光庇护我们！
```

魔王觉醒前后，勇者喊话应该发生变化。

觉醒前：

```text
他们认为自己在讨伐怪物。
```

觉醒后：

```text
他们意识到自己只是祭品。
```

系统播报示例：

```text
第一枚勇者硬币已投入。
腐血筹码已到账。
胚胎正在成形。
他们终于意识到，讨伐军只是祭品。
开奖完成：魔王降临。
```

## 15. 黑客松最小可玩版本

2 天黑客松版本必须优先保证完整闭环，而不是内容数量。

最小可玩标准：

```text
标题界面
邪恶核心移动
小怪围绕核心
小怪自动攻击
勇者从四周刷出
勇者死亡掉腐血
腐血磁吸和过期
经验满触发老虎机
至少 6 个升级奖励
花费腐血筹码升格至少 1 个精英小怪
胚胎值满触发最终开奖
至少 3 个魔王形态结果
魔王觉醒后明显变强
圣骑士 Boss 登场
击败 Boss 进入屠杀报告
可以重新开始
```

建议首版内容规模：

```text
2 种小怪
2 种普通勇者
1 个圣骑士 Boss
6-8 个老虎机奖励
2 个精英小怪升格结果
3 个魔王形态
1 个觉醒大招
1 个结算页
```

暂缓内容：

```text
亵渎赌局
复杂圣坛事件
局外成长
完整剧情
大量敌人种类
完整魔王组合库
复杂 Boss AI
```

## 16. 体验验收

一个合格的 Demo 应该让玩家完整感受到：

```text
我带着一群弱小怪物苟活。
勇者不断冲进地牢。
我杀勇者获得腐血筹码。
我通过老虎机获得成长。
我花费筹码把指定小怪养成精英怪。
我把小怪赌成魔王。
魔王诞生后开始反杀。
最后击败圣骑士 Boss。
我看到一份属于魔王的屠杀报告。
```

最终验收句：

```text
玩家玩完后能记住：“这是一个用勇者当筹码，靠老虎机孵化魔王的像素割草游戏。”
```
